# 02 — When a task is stuck

```
Task <task-id> is stuck. Without changing code yet:

1. Read the plan, the verifier's last report and the reviewer's last findings.
2. Explain the root cause in plain terms: is it the data (gaps, clouds,
   wrong collection), the science (method doesn't fit), or the code?
3. Give me 2–3 options with trade-offs, and recommend one.
4. If an option changes the method, draft the ADR text for it.

Wait for my choice before editing anything.
```
