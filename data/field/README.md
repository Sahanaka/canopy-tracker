# Field data

Committed here: GeoJSON files of field points exported from QField (small, public land only). The form, the schema and
the export steps are in [`docs/field/form.md`](../../docs/field/form.md). Check a file with
`python -m highland.io data/field/<file>.geojson`.

Not committed (git-ignored): `photos/` (pictures carry GPS positions) and `private/` (points on private land, same
schema). Never put homes or other people's details in any file.
