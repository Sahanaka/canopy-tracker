# Plan — M0.1 Package and environment

## Goal

Make the repo an installable, linted, tested Python package (`highland`), with a pinned conda environment that
works in CI (micromamba, linux-64) and on a laptop (macOS/Windows/Linux).

Acceptance criteria (docs/ROADMAP.md):
- `environment.yml` with pinned versions of the stack in CLAUDE.md; `pyproject.toml` installing `src/highland` in editable mode.
- `ruff`, `pytest`, `nbstripout`, `pre-commit` configured; `pre-commit run --all-files` passes.
- `src/highland/__init__.py` and empty module stubs from the CLAUDE.md layout; one passing smoke test.

## Design

Files to add (no analysis logic in this task):

- `environment.yml` — `name: highland`, `channels: [conda-forge]` only (`nodefaults` listed so Anaconda's default
  channel is never used), `python=3.13.*`, every direct dependency above as `pkg==X.Y.Z`, plus `pip`. No `pip:`
  section unless a package is missing on conda-forge (none expected).
- `environment-3d.yml` (if D3 accepted) — only `pyvista`, `trame`, `trame-vtk`, `trame-vuetify`, `pytest-playwright`,
  applied on top with `micromamba install -n highland -f environment-3d.yml` (or `conda env update`); then
  `playwright install chromium` locally. Not used by CI.
- `pyproject.toml`:
  - `[build-system]` hatchling; `[project] name = "highland"`, `requires-python = ">=3.12"`, `dynamic` or static
    `version = "0.1.0"`, `dependencies` per D4; src layout (`[tool.hatch.build.targets.wheel] packages = ["src/highland"]`).
  - `[tool.ruff]` `line-length = 100`, `target-version = "py312"`, `src = ["src", "tests"]`; lint `select =
    ["E", "F", "W", "I", "UP", "B", "NPY"]`. Notebooks are linted/formatted by default in ruff ≥ 0.6 (no
    `extend-include` needed); add `[tool.ruff.lint.per-file-ignores] "notebooks/*" = ["E402"]`.
  - `[tool.pytest.ini_options]` `addopts = "--strict-markers -ra"`, `testpaths = ["tests"]`,
    `markers = ["network: needs internet; skipped in CI", "viewer: browser test via pytest-playwright; local only"]`.
- `.pre-commit-config.yaml` (per D5): ruff (lint `--fix` + format, incl. notebooks), nbstripout, and
  `pre-commit-hooks` 6.0.0 (`check-yaml`, `end-of-file-fixer`, `trailing-whitespace`, `check-added-large-files`
  with a limit, e.g. 5 MB, so rasters don't sneak in).
- `.gitignore`: Python caches (`__pycache__/`, `*.egg-info/`, `.pytest_cache/`, `.ruff_cache/`), `.ipynb_checkpoints/`,
  `.venv/`, `.DS_Store`, and `outputs/*` with `!outputs/README.md`. Do **not** ignore `data/` or `viewer/data/`
  (both committed).
- `outputs/README.md` — what lives here and that each `outputs/<task-id>/` has its own README.
- `src/highland/__init__.py` — docstring + `__version__` (from `importlib.metadata`, fallback `"0+unknown"`).
- 12 stubs: `aoi, stac, masking, indices, composites, landsat, change, terrain, landcover, io, viz3d, viewer` —
  each a module docstring only (one line: purpose from CLAUDE.md). No functions yet, so no placeholders that look
  like real logic. `viz3d`/`viewer` must never import pyvista/playwright at module top level (later tasks import lazily).
- `tests/test_smoke.py` — see Tests.
- `notebooks/`, `data/aoi/`, `data/field/` are not created here (M0.3/M0.4/M1.1 create them).

## Decisions needed

- **D1 Python version.** Options: 3.12 / 3.13 / 3.14. rioxarray 0.23, rasterio 1.5 and numpy 2.5 need ≥3.12; 3.15 is
  brand new. **Recommend `python=3.13.*` in env, `requires-python >=3.12`**, and update CLAUDE.md "Stack" to
  "Python 3.12+". Confirm 3.13 builds exist on conda-forge for every pin in Step 1.
- **D2 Exact pins vs lockfile.** (a) `==` pins on direct deps only in `environment.yml` — simple, readable, works with
  `setup-micromamba` today; transitive deps (GDAL, PROJ) still float. (b) conda-lock 4.0.3 → `conda-lock.yml` for
  linux-64, osx-64, osx-arm64, win-64; fully reproducible, but adds a regeneration step and a large generated file.
  **Recommend (a) now**, with an ADR that records a later move to (b) if a transitive upgrade ever breaks a result.
- **D3 Heavy optional deps (pyvista/trame/VTK, playwright).** (a) all in `environment.yml` — one env, but CI pulls VTK
  and browsers it never uses; (b) separate `environment-3d.yml` layered on the main env; (c) pip extras
  `[3d]`/`[viewer]` in pyproject — mixes pip VTK wheels into a conda env. **Recommend (b)**, plus viewer tests use
  `pytest.importorskip("playwright")`, and M0.2 changes CI to `-m "not network and not viewer"`.
- **D4 `[project].dependencies`.** (a) empty — conda env is the single source of truth (CI uses `--no-deps`);
  (b) unpinned names — documents deps for pip users but can drift. **Recommend (a)** with a comment pointing to
  `environment.yml`.
- **D5 pre-commit hook sources.** (a) `repo: local`, `language: system` for ruff and nbstripout, using the env's pinned
  binaries — one version source, works offline; (b) upstream hook repos (`ruff-pre-commit`, `nbstripout`) with
  `rev` matching the env pins — standard, but two places to bump. **Recommend (a)** for ruff/nbstripout; upstream
  `pre-commit-hooks` 6.0.0 for the generic checks.

## Risks

- A pinned version lacks a conda-forge build for one platform (esp. win-64 or osx-arm64) or for Python 3.13 →
  solver fails on a laptop though CI passes. Mitigate: Step 1 dry-run solves for all four platforms
  (`micromamba create --dry-run --platform <p> -f environment.yml`).
- Exact pins over-constrain the solver (e.g. odc-stac vs xarray/dask ranges). If unsolvable, relax the one
  conflicting pin to the newest solvable version and record why in the plan.
- `pip install -e . --no-deps` uses build isolation and fetches hatchling from PyPI: fine in CI, fails offline.
  Optionally add `hatchling` to the env and document `--no-build-isolation` for offline use.
- `pre-commit` hook installs need network the first time (upstream `pre-commit-hooks`).
- Pinned versions age; no automated bump yet (out of scope; possible later Dependabot/renovate task).
- PyPI-only-verified pins (dask, shapely, sklearn, matplotlib, jupyterlab, pytest, pre-commit) may lag on conda-forge.

4. Add `tests/test_smoke.py`. Commit `test: add import smoke test`.
5. Add `.gitignore` and `outputs/README.md`. Commit `chore: add gitignore and outputs readme`.

7. Write ADRs for accepted decisions (D1–D3 at least: `docs/decisions/0003-python-version.md`,
   `0004-environment-pinning.md`, `0005-optional-3d-env.md`), update CLAUDE.md "Stack" Python version, tick M0.1
   in ROADMAP. Commit `docs: record environment decisions`.
